# PMO EPC Platform

# Functional Specifications

Version : 0.1

---

# 1. Présentation

PMO EPC Platform est une plateforme intégrée destinée à la gestion de projets industriels de type :

- Engineering
- Procurement
- Construction
- Oil & Gas
- Energie
- Mines
- Infrastructures

L'objectif est de regrouper dans une seule plateforme les fonctions habituellement réparties entre plusieurs logiciels :

- Primavera P6
- Microsoft Project
- ProDom
- SharePoint
- SAP PM
- Excel
- Power BI

La plateforme doit permettre de piloter l'ensemble du cycle de vie d'un projet.

---

# 2. Principes fonctionnels

# 19. Philosophie de développement

Les règles suivantes doivent toujours être respectées.

• Une fonctionnalité n'est développée qu'une seule fois.

• Les composants graphiques sont mutualisés.

• Les calculs métier sont centralisés dans les services.

• Les vues Django restent les plus légères possible.

• Les templates ne contiennent jamais de logique métier.

• Les référentiels sont utilisés partout afin d'éviter les valeurs codées en dur.

À terme, PMO EPC Platform doit devenir une plateforme intégrée permettant de gérer l'ensemble du cycle de vie d'un projet EPC :

Opportunité

↓

Études

↓

Ingénierie

↓

Achats

↓

Fabrication

↓

Construction

↓

Commissioning

↓

Handover

↓

Exploitation

↓

Archivage

L'objectif n'est pas seulement de gérer un planning ou des documents, mais de disposer d'une plateforme unique de pilotage des projets industriels, intégrant les dimensions techniques, documentaires, financières et organisationnelles.
