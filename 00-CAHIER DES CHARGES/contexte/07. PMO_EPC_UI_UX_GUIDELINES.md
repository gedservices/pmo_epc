# PMO EPC Platform

# UI / UX Guidelines

Version : 1.0

---

# Objectif

Ce document définit les règles de conception graphique et ergonomique de PMO EPC Platform.

Tous les nouveaux écrans, composants et modules doivent respecter ces règles afin de garantir :

- une interface homogène
- une navigation cohérente
- une maintenance facilitée
- une meilleure expérience utilisateur

Ces règles s'appliquent à tous les modules de la plateforme.

---

# Philosophie générale

PMO EPC est un outil professionnel destiné à des utilisateurs travaillant quotidiennement sur des projets industriels complexes.

L'interface doit privilégier :

- la lisibilité
- la densité d'information
- la rapidité d'accès
- la cohérence
- la simplicité

Le design doit rester sobre.

Il ne s'agit pas d'un site vitrine mais d'un logiciel métier.

# Responsive

Desktop prioritaire.

Tablet compatible.

Mobile secondaire.

Le logiciel est destiné principalement aux grands écrans.

---

# Performance

Limiter les requêtes.

Éviter les tableaux trop volumineux.

Privilégier les composants réutilisables.

---

# Accessibilité

Contrastes suffisants.

Icônes accompagnées d'un texte.

Navigation clavier fonctionnelle.

Messages d'erreur explicites.

---

# Règles de développement

Avant de créer un nouveau composant, vérifier qu'il n'existe pas déjà.

Les composants communs doivent être enrichis plutôt que dupliqués.

Le code HTML doit rester simple.

La logique métier reste dans les services.

# Objectif final

Quel que soit le module (Projet, Commande, GED, Planning, Coûts, Risques ou Reporting), un utilisateur doit immédiatement retrouver :

- la même navigation
- les mêmes composants
- les mêmes couleurs
- les mêmes actions
- la même organisation des pages

La cohérence de l'interface constitue un objectif majeur de PMO EPC Platform.
